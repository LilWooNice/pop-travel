# Lil Woo游记 · Lil Woo's Travel

一个大胆波普风的个人旅行摄影 / 二次创作作品站。**纯单文件网页**（`index.html`），零依赖、无需安装任何环境，双击用浏览器打开即可。

## 现在看到的是什么

页面里的 8 张"照片"是我画的波普风占位插画（内嵌 SVG），风格、排版、交互都是最终效果，方便你先看整体感觉。换成真照片后这些插画就自动退场。

## 换成你自己的照片（3 步）

1. **建文件夹**：在 `index.html` 旁边建一个 `photos/` 文件夹，把照片放进去（建议横图、4:3 或 3:2，每张 1–2 MB 内）。
2. **改数据**：用任意编辑器打开 `index.html`，搜索 `PHOTOS`，你会看到这样的条目：

   ```js
   { art:'desert', title:'沙丘上的日落', location:'甘肃 · 敦煌', date:'2025.05',
     note:'正午拍的沙脊线，后期压成波普双色调……',
     tags:['风光','二次创作'] },
   ```

   把它改成（删掉 `art`，加上 `src`）：

   ```js
   { src:'photos/dunhuang.jpg', title:'沙丘上的日落', location:'甘肃 · 敦煌', date:'2025.05',
     note:'你自己的注解……',
     tags:['风光','二次创作'] },
   ```

3. **刷新浏览器**。数量随意增减，标签（tags）会自动生成筛选按钮，顶部统计数字也会自动更新。

> 站名「Lil Woo游记」：大标题、`<title>`、页脚版权里各有一处，直接改文字即可。
> 联系方式：页脚的 GitHub 贴纸链接在 `index.html` 底部，直接改 `href`。

## 发布上线（可选）

任选其一，都免费：

- **GitHub Pages**：建一个仓库，把 `index.html` 和 `photos/` 传上去，Settings → Pages 开启即可，得到 `https://你的用户名.github.io/仓库名`。
- **Vercel / Netlify**：把文件夹拖进网页端部署界面，几十秒拿到网址。

发布前记得把页脚的社交链接换成真的。

## 功能一览

- 🎨 波普风视觉：高饱和撞色、粗黑描边、硬阴影、网点纹理、贴纸式排版
- 🏷 标签筛选（从数据自动生成）
- 🔍 点击卡片开灯箱看大图 + 注解，支持键盘 ← → 翻页、Esc 关闭
- 📱 手机端自适应，动效尊重系统"减少动态效果"设置
